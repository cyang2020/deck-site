# 小园 · 设计构思 v4(工作名:小园 / Her Garden)

> 一句话:整个 App 是一座属于她的园子。推开篱笆门走进去,
> 花房里晾着她的照片日记,小屋里住着替她收烦恼的布娃娃,
> 花田里开着"后来没事了"的烦恼,邮筒里躺着节气寄来的种子。
> 园子随真实的季节、天气、昼夜变化,随年份一年年长深。
>
> 为一位温柔可爱、热爱记录生活,却活在别人的期待与比较里、
> 怕让人失望、怕麻烦别人的人而做。
> 完全独立的产品:独立命名、独立仓库、独立视觉。文档暂存于此,建仓后迁出。

---

## 0. 心理主轴(所有设计决定的根)

1. **这里没有观众,也没有任何会失望的对象。**
   无社交、无点赞、无指标、无进度、无排名。娃娃对她没有期待,园子对她没有期待,
   连 App 自己都不许表达期待("期待你明天再来"一律禁止)。
   她的一生都在被注视,园子是唯一不被注视的地方。

2. **疗愈全部藏在可爱里。**
   别扭的人一旦闻到"这个东西想修理我"的味道会立刻抗拒。
   所以界面上永远只有园子里的日常之物,没有一个心理学词汇:
   情绪藏在照片背面,倾诉藏在布娃娃,认知调整藏在自然的活法里。

3. **是园子,不是农场游戏。**
   没有货币、没有升级、没有任务、没有产量;不用浇水施肥,**没有任何东西会枯萎**。
   植物只随真实时间生长。离开一个月,回来只是换了季节,还多了几株野花——
   "你不在的时候,风替你浇了水。"

## 1. 世界观:一座园子,处处可去

不做 tab。一整幅可以横向漫步的园景(视差滚动),点进各处开启功能,任何功能 ≤ 2 步可达。
园景随真实节气、当地天气、昼夜变化:惊蛰有虫鸣,霜降叶红,雨天园子也下雨,夜里是月光。

| 园中之处 | 功能 |
|---|---|
| 篱笆门 | 打开 App = 推门进园(轻轻的吱呀一声) |
| 花房(玻璃暖房) | 照片日记:卡片用小木夹晾在绳上 |
| 小屋 | 布娃娃住处;倾诉与晚安仪式 |
| 花坛 | 她亲手种的花(心情与一句话种下去) |
| 花田(小屋后) | 娃娃打理:每朵花是一个"后来没事了"的烦恼 |
| 小溪 | 放下的烦恼折成纸船漂走;溪边可坐 |
| 大树与秋千 | 什么都不用做的地方;呼吸藏在秋千的摇摆里 |
| 邮筒 | 节气寄来的种子包 + 园子偶尔的一封短信 |

## 2. 种东西:万物皆种子

园子可以种,而她放进 App 的一切,也都以"种下"的方式落进园子:

- **心情/一句话日记 → 花坛的花。** 选一包种子,写一句话(可不写),种进花坛。
  几天后开花,花色与当时的节气、心情天气有关。心情不打分,用天气:晴/多云/小雨/雷阵雨——
  雨天没有好坏,雨天也是园子需要的。
- **烦恼 → 花田的花。** 说给娃娃的烦恼,放下之后由娃娃种进花田(见 §4)。
- **纯粹想种 → 就种。** 不需要理由,布置园子本身就是表达:花往哪儿种、小径通向哪、
  石头摆哪儿,都是她的。园艺即创作,无对错。
- **种子从哪来 → 邮筒。** 每个节气,邮筒收到一包应季种子(谷雨有新绿系,霜降有红叶系)。
  种子随时间自然到来,不靠任务解锁、不靠连续签到——收集的快乐,没有绩效的压力。
  攒下的种子放在**种子盒**里,一格一格,满足收集癖。
- **多年生。** 有的种子长成多年生植物甚至小树,第二年、第三年才开花结果。
  园子随年份一年年长深,这是任何内容运营都替代不了的长期理由。

## 3. 花房:照片日记

tinytype 式思路:照片不是存进相册,而是做成一张有质感的小卡,晾在花房的绳上。

- **卡片即质感**:拍立得、胶片条、票根几种"纸",自动盖手写体日期戳与当日天气。
  滤镜不叫滤镜,叫"纸"和"胶卷"。奶油色、圆角、手账贴纸,小可爱风。
- **心流三步**:拍/选图 → 自动风格化(默认就好看)→ 写一行字。
  木夹"嗒"一声夹上绳,轻轻晃两下。全程 30 秒,可以只晾图不写字。
- **背面的话**:每张卡可翻面。正面给回忆,背面给情绪——最 emotion 的话写在背面。
  背面默认蒙毛玻璃,长按才显形,保护她不被旧情绪突袭。写在背面,即被承载。
- **蜡封**:特别重要的一张按一枚小蜡封,在花房里微微发亮。
- 按月成绳,整面花房可以翻阅,像走回某个月份。单卡可导出成图,App 内无任何社交。

## 4. 小屋:解忧娃娃

人文的根:危地马拉解忧娃娃——烦恼说给小娃娃,睡前放枕头下,夜里它替你担心。

- **初见即亲手缝它**:选布料花色、选表情、取名字。粗针脚、纽扣眼睛。
- **麻烦它就是它的工作**:她怕麻烦别人,而收烦恼是娃娃唯一会做、也最爱做的事。
  她说(打字,或按住娃娃的手说语音;语音不转文字,只是被收着),
  它认真点头,把烦恼仔细叠好,收进胸前小布袋:"这个给我吧,你拿着太重了。"
- **只收,不劝,不是 AI**:不接大模型、不给建议、不分析。只有一套笨拙可爱的固定反应。
  布娃娃不会说漂亮话,但永远不会说错话——对怕被评价的人,
  "不够聪明所以绝对安全"的倾听者好过任何会回话的东西。零服务器,话只在她手机里。
- **烦恼的生命周期(全 App 最重要的机制)**:
  收下 → 睡前放枕头下陪她熄灯 → 卡片随时间褪色 → 隔段时间娃娃轻轻问一次
  "上次那个,还沉吗?" → 还沉:"那我继续拿着"(永不追问);
  不沉了:折成纸船放进小溪漂走,娃娃在花田种下一株新芽。
  **花田里每一朵花,都是一个"后来没事了"的烦恼**——
  "这次一定完蛋"的反证,由她自己一年年攒出来。
- **晚安仪式**:夜里的小屋,一盏灯。把今天交给枕头底下,娃娃陪她熄灯。

## 5. 秋千与邮筒

- **大树下的秋千**:什么都不用做的地方。坐上去,只有风声、吱呀声、虫鸣与光。
  不承载任何练习和功能——"什么都不用做"就是它的全部。
- **邮筒**:除了种子包,园子偶尔(节气一封,宁缺毋滥)寄来一张小小的便签——
  不是知识(她是专家),是**自然的活法**:
  "苔藓不羡慕乔木,它们不在同一场比赛里。"
  "冬天的树没有为落叶道歉。"
  "雨下了三天,云没有觉得抱歉。"
  她被期待、比较、怕让人失望困住,而自然是唯一不比较、不期待、不失望的东西。
  这些话由园子说出来不算说教——园子自己就是这么活的。

## 6. 总原则

1. 永不制造亏欠感:无签到、无中断提示、无枯萎。
2. 30 秒也算来过;一切动作可跳过。
3. 完全私密、离线、零服务器;数据一键导出(照片原件 + 文本);可选 iCloud(她自己的账号)。
4. 这是屋子,不是桥:没有任何"来自某人"的东西,不需要她回应任何人。
5. 不替代专业帮助:小屋抽屉里一行小字,通向专业资源;
   连续多日"雷阵雨"时,园子只是变得更安静,绝不弹窗关切。
6. 文案永不评价、不祈使、不煽情:✅"都还在。" ❌"坚持记录,你真棒!"

## 7. 技术方案

- iOS 原生(SwiftUI + SwiftData;园景用 SwiftUI Canvas/SpriteKit 视差场景)。
- 零服务器、无外部依赖:节气表本地预置几十年;天气用 WeatherKit,取不到则按节气与昼夜退化。
- 语音以加密文件本地存;全部数据可导出。
- 桌面小组件:园子一角(随季节昼夜变化)+ 花房最新一张卡。

## 8. MVP 切分

- **v0.1 园子与花房**:单季静态园景(先做秋天)+ 花房照片卡(两种纸 + 背面的话)+ 花坛种心情种子。
- **v0.2 娃娃**:缝娃娃、收烦恼、褪色与回访、花田与纸船。
- **v0.3 四时**:四季/昼夜/天气场景、邮筒(种子包 + 节气便签)、秋千、晚安仪式。
- **v1.0**:蜡封、种子盒图鉴、多年生植物、小组件、导出。
