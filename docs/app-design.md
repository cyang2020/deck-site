# 四时小园 · 设计构思

> 一句话:一个跟着真实节气生长的口袋小园子。为一位喜欢自然与人文、温柔可爱、
> 但近来压力很大、常常不够相信自己的人而做。目标是**长期、安静、不带任何负担的陪伴**。

---

## 1. 她是谁 → 设计上怎么翻译

| 她的特质 | 设计翻译 |
|---|---|
| 压力大 | 做减法:打开的第一秒就该是放松的。柔和的色彩、自然的声音、没有信息流、没有红点、没有推送轰炸。一次使用 30 秒也完整。 |
| 不自信 | 绝不做评分、排名、连续打卡、"你已中断 N 天"。反过来做**证据收集**:帮她看见自己已经做到的事。文案永远不评价,只陈述和陪伴。 |
| 喜欢自然 | 内容跟着真实世界走:二十四节气、七十二物候、当地天气、昼夜。App 像一扇窗,而不是一块屏。 |
| 喜欢人文 | 每天一件"小而美"的东西:一句应景的诗、一幅画、一件博物馆藏品的小故事。慢内容,不是资讯。 |
| 温柔、可爱 | 视觉手绘质感、圆润;园子里住一只小生灵(小狸猫/刺猬/鸟),它不催促、不布置任务,只是在。 |
| 要能长期用 | 把**时间**做成内容引擎:内容随四季轮回,园子随年份沉淀,数据长成她自己的"年轮"。第二年、第三年打开,和第一年不一样。 |

## 2. 总原则:温柔的减法

1. **永不制造亏欠感。** 没有连续签到、没有枯萎惩罚、没有"错过"。她离开一个月,回来时园子只是安静地换了季节,还多开了几朵野花——"你不在的时候,风替你浇了水。"
2. **30 秒也算来过。** 每日全部动作都可跳过,单独任何一个都构成完整的一次使用。
3. **完全私密、完全离线。** 没有账号、没有服务器、没有任何数据回传(延续「深水区」的理念)。她写下的一切只在她手机里,并且要让她明确知道这一点——只有确信私密,人才敢把真心话写进去。
4. **这是屋子,不是桥。** App 里不做社交、不做分享回传、不做"来自某人的消息"。它完全属于她,不需要她回应任何人。
5. **不替代专业帮助。** 状态很糟的入口里,安静地放一行专业求助资源,不说教。

## 3. 核心概念:四时小园

打开 App,看到一个小园子。园子的样子由三件真实的事决定:**节气、当地天气、时刻**(清晨/白天/黄昏/夜晚)。惊蛰有虫鸣,谷雨有新绿,霜降叶子变红,大雪园子盖上雪。晚上打开,是月光下的园子。

每天可做三件小事(都可选、都可跳过):

### ① 收一枚「今日物候卡」
延续做「深水区」的抽卡手感。每天一张:今日节气物候 + 一句应景的诗文或一幅画 + 一条自然小知识。收集起来成为她的「物候历」。内容池 ≥ 366 天不重复,随年份轮换批次。

### ② 种一颗「一句话种子」
一句话记录今天,或者只选一个"心情天气"(晴 / 多云 / 小雨 / 雷阵雨)。**用天气而不用 1–10 分**——对不自信的人,给自己打低分本身就是伤害;而雨天不是坏天气,园子也需要雨。写下的话变成一颗种子种进园子,过几天开成花。花的种类和当时的节气有关。

### ③ 逛逛园子里的三个小房间

- **证据罐** — 放"我做到过的事"。每条小成就是一件藏品,配一张手绘展签,像她自己的小博物馆。低落的时候按一下罐子,不讲道理,随机展出三件藏品。
- **晚安灯** — 睡前的降落伞:一段美的文字 + 三分钟自然白噪音(雨声/林间/溪流,随季节换)+ 一次呼吸引导。针对夜里反刍思维。
- **雷阵雨角落** — 她标记"雷阵雨"时,整个 App 自动变得更安静:只有呼吸、白噪音、和一句"你可以什么都不做"。角落里一行小字通向专业求助资源。

### ④ 年轮(长期机制)
- 每个节气结束,生成一页"节气小结":这半月园子的样子、她收的卡、开出的花。
- 周年时长成一圈"年轮":她的一年四季、雨天和晴天、证据罐里新增的藏品。
- 第二年春分打开,会看到"去年春分,你写过——"。时间越久,这个 App 越厚。

## 4. 备选方向(可并入)

| 方案 | 核心 | 处理 |
|---|---|---|
| 小小证据馆 | 纯自信方向,成就博物馆 | 已并入,即「证据罐」 |
| 一平米自然 | 每天拍一张身边的自然(天空/叶子/光斑),攒成自己的博物志 | 适合 v2:拍的照片可以"贴"进当日园景 |
| 纸间灯火 | 纯人文方向,每晚一盏灯:文字+白噪音+呼吸 | 已并入,即「晚安灯」 |

## 5. 文案调性(文案即产品)

- 不用祈使句,不用评价句,不煽情。
- ✅ "今天的园子有你,真好。" ❌ "坚持记录,你真棒!"
- ✅ "你不在的时候,风替你浇了水。" ❌ "你已经 7 天没来了!"
- ✅ "雨天也是园子需要的。" ❌ "调整心态,明天会更好!"
- 小生灵不说教,大多数时候它只是睡觉、追蝴蝶、把她写的种子叼去埋好。

## 6. 长期可用的技术方案

- **形态**:iOS 原生(延续「深水区」的路线,SwiftUI),或 PWA(免上架、加主屏、可离线)。建议 iOS 原生:体验更细腻,而且你已经走通过一次上架流程。
- **零服务器**:内容池(节气 × 物候 × 诗文 ≥ 366 条)全部打包在本地;数据存本地(SwiftData / 文件),提供一键导出备份。没有服务器,就没有"哪天服务器停了 App 就死了"——这是"长期能用"最硬的保障。
- **免维护的活性**:所有随时间变化的内容按日历规则驱动(节气表可预置几十年),不依赖任何外部 API;天气可用系统 WeatherKit,拿不到就优雅退化为只按节气变化。
- **小组件**:桌面 Widget 显示今日园景一角 + 节气,是最低打扰的"长期存在感"。

## 7. MVP 切分

- **v0.1(骨架)**:节气园景(四季 × 昼夜的静态插画即可)+ 每日物候卡 + 一句话种子(心情天气)。
- **v0.2(心)**:证据罐 + 晚安灯 + 雷阵雨角落。
- **v0.3(时间)**:节气小结、年轮、桌面小组件。
- **v2**:一平米自然(拍照入园)、更多园景细节与小生灵动画。
