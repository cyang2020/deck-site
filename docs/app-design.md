# 小小博物馆 · 设计构思(工作名:格物)

> 一句话:一座只属于她的、装在口袋里的小小博物馆。
> 为一位以自然与可持续为研究方向的学者而做——她温柔、可爱,热爱收集与记录,
> 但常年压力很大、不太敢相信自己。目标是**长期、安静、不带任何负担的陪伴**。
>
> 本 App 为完全独立的产品:独立命名、独立仓库、独立视觉,与本仓库现有产品无任何关联。
> 设计文档暂存于此,建仓后迁出。

---

## 0. 一个关键的倒转

她研究自然——自然是她的**工作**。所以这个 App 不做任何"内容喂养":不推送自然知识、
不做每日科普卡片(在专家面前谈物候,只会显得单薄,甚至像在给她加班)。

倒转过来:**App 里所有内容都由她自己收进来。** 它不是一本要她读的杂志,
而是一只装她所注意到的世界的柜子。给她的是"作为休息的自然",不是"作为课题的自然"。

这个倒转同时解决了"长期能用"的最大隐患:不需要维护任何内容池,
内容是她的人生,永远不会过期。她收集得越久,这座博物馆越厚,越无可替代。

## 1. 她是谁 → 设计上怎么翻译

| 她的特质 | 设计翻译 |
|---|---|
| 爱收集、爱记录很多东西 | 收集就是核心玩法:一切进入 App 的东西都是"藏品",有展签、有柜格、可布展。收藏家最大的快乐——**自己定义分类**——做成核心功能(自建抽屉)。 |
| 自然是她的专业 | App 对自然零说教。她是策展人,App 只是她的柜子和展签纸。 |
| 喜欢人文 | 形式语言全部取自人文世界:博物馆、展签、多宝格、标本册、年度特展。 |
| 常年压力大(博士生活) | 她的生活里已经全是"必须记录的东西"(数据、文献、进度)。这里**只收想留下的,没有任何必须**:无打卡、无统计、无完成度、无必填项。收一件东西 ≤ 30 秒。 |
| 不自信 | 专设「做到的事」抽屉:小成就作为藏品被郑重展出。读博的人常觉得自己一事无成——这个抽屉是反证的实物陈列。且整个 App 无任何评分与产出指标:**这里收藏的是她这个人,不是她的产出。** |
| 温柔、可爱 | 手绘质感、圆润;博物馆里住一位小小管理员(刺猬/狸猫),夜里替她把新藏品摆上架、掸掸灰。它不催促、不布置任务。 |
| 要能长期用 | 收藏天然复利:重逢机制 + 年度特展 + 柜子随年份加深。第三年打开和第一年完全不同。 |

## 2. 总原则

1. **永不制造亏欠感。** 没有连续签到、没有"你已 N 天没来"。离开一个月,回来只会看到小管理员把柜子擦得干干净净,说:"都还在。"
2. **30 秒也算来过。** 唯一的核心动作是「收进」,拍一张/写一句即可,其余全部可选。
3. **完全私密、离线、数据可带走。** 无账号、无服务器、无任何数据回传;一键导出为纯文本 + 照片文件夹(Markdown/JSON)。对一位科研工作者,"数据是我的、格式是开放的"是最根本的信任。
4. **这是屋子,不是桥。** 不做社交、不做分享回传、没有任何"来自某人"的东西。它完全属于她,不需要她回应任何人。
5. **不是效率工具。** 不做搜索优先的界面、不做标签体系、不做统计图表。博物馆是用来逛的,不是用来查的。
6. **不替代专业帮助。** 最安静的角落里放一行专业求助资源,不说教。

## 3. 核心概念:她的小小博物馆

### 唯一的核心动作:「收进」
看到什么、想到什么、做到了什么——拍一张或写一句,选一个抽屉,收进。
自动记下日期与时节;地点可选。30 秒完成。

### 抽屉(柜格)
默认几只,更重要的是**她可以自建**(取名 + 选一枚小图标)。收藏家的快乐一半在藏品,一半在分类法。

- 「拾到的自然」— 一片叶、一声鸟、一束光斑
- 「拾到的句子」— 偶遇的诗句、画、展览、书页
- 「做到的事」— 大小成就,反证"一事无成"的实物陈列
- 「好日子」— 值得留下的时刻
- (她自建的)—「路上的猫」「好喝的茶」「奇怪的石头」……

### 展签
每件藏品配一张手绘风格的博物馆展签:编号、日期、时节、她写的一句话。
藏品因此不是"一条记录",而是"一件被郑重对待的东西"。

### 重逢
博物馆的深处按钮:随机展出一件旧藏。"三年前的今天,你收进了——"。
收藏的意义一半在收,一半在多年后的偶然重逢。

### 年度特展
每年,小管理员布一场只对她开放的特展:今年收进了多少件、每个季节的代表藏品、
「做到的事」抽屉的全部展出。做成一本可翻页的小册子,可导出留存。

### 雷阵雨角落
她标记"今天是雷阵雨"时,整个 App 自动进入最安静的状态:
只有呼吸引导、一段白噪音、一句"你可以什么都不做",
以及小管理员从「做到的事」抽屉里随机取出的三件旧藏。
角落里一行小字,通向专业求助资源。

## 4. 心理安全细节

- 心情不打分,用天气(晴/多云/小雨/雷阵雨)。给自己打低分本身就是伤害;而雨天没有好坏。
- 文案永远不评价、不祈使、不煽情:
  - ✅ "第 214 号藏品,已上架。" ❌ "坚持记录,你真棒!"
  - ✅ "都还在。" ❌ "你已经 30 天没来了!"
  - ✅ "雷阵雨的日子,博物馆闭馆休息,你也是。" ❌ "调整心态,明天会更好!"
- 小管理员从不说教;大多数时候它只是在打盹、擦展柜、把新藏品摆正。

## 5. 技术方案(为"很多年后还打得开"设计)

- **独立产品**:新仓库、新名字、新视觉,与现有任何产品无关。
- **形态**:iOS 原生(SwiftUI + SwiftData)或 PWA。倾向 iOS 原生:相机/相册、桌面小组件、
  本地通知(仅用于她自己设定的事)体验更好。
- **零服务器**:无后端、无外部 API 依赖;节气/时节表本地预置几十年。
  没有服务器,就没有"哪天服务停了 App 就死了"。
- **数据主权**:本地存储;一键导出 Markdown + JSON + 照片原文件;可选 iCloud 备份(她自己的账号)。
- **小组件**:桌面 Widget 轮展一件旧藏("重逢"的最低打扰形态)。

## 6. MVP 切分

- **v0.1(骨架)**:收进(拍照/一句话)+ 三只默认抽屉 + 展签 + 逛柜子。
- **v0.2(收藏家)**:自建抽屉 + 重逢按钮 + 心情天气。
- **v0.3(时间)**:年度特展 + 桌面小组件 + 雷阵雨角落 + 导出。
- **v2**:小管理员的动画细节、时节氛围(柜子的光线随季节与昼夜变化)。

## 7. 名字候选

- **格物** — 取《大学》"格物致知";"格"亦是柜格之格。收东西进格子,即格物。
- **拾集** — 拾起、收集;"十日为一集"。
- **小小博物馆** — 直白温柔,App 图标即一只多宝格小柜。
- 英文名向:Wunder(取 Wunderkammer 珍奇柜)/ Shelves / Keep 待定。
